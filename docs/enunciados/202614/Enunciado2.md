# Sistema de Gestión de Recursos Humanos

La empresa CorporateHR Solutions lo ha contratado para desarrollar una aplicación llamada "RH Pro" que permitirá a un gerente de recursos humanos gestionar todo lo relacionado con empleado y departamento de la empresa. El gerente de recursos humanos debe estar pendiente de mantener actualizada la información de empleados y departamentos. Para iniciar el contrato, la empresa lo cita a una reunión para especificar sus necesidades, como se comenta a continuación.

Al iniciar la aplicación el gerente de recursos humanos verá una pantalla principal, donde podrá ver el logo de CorporateHR Solutions, la descripción de la aplicación "EmployeeManager Pro", una opción para agregar empleado, otra para ir al listado de departamentos y el listado de empleados disponibles. En el listado de departamentos se muestra nombre, ubicación, presupuesto y botones para editar o borrar departamento, siempre y cuando no tenga empleados asociados. En la pantalla de departamentos, el gerente de recursos humanos encuentra también una opción para agregar departamento nuevo y otra para volver a la pantalla principal.

En la opción para agregar empleado, el gerente de recursos humanos podrá registrar nombre, cargo, salario, fecha de ingreso y seleccionar departamento de una lista disponible. Desde la pantalla para agregar empleado el gerente de recursos humanos puede ingresar a una opción para gestionar departamentos si necesita agregar uno nuevo.

El listado de empleados de la página principal muestra para cada empleado nombre, cargo, salario, fecha de ingreso, una opción que permite editar toda la información, otra que permite eliminar y una opción ver detalles. La opción de ver detalles permite consultar información completa incluyendo los datos de departamento asociado.

Además, la aplicación debe incluir una funcionalidad de "Reporte de Departamentos por Popularidad" que permite al gerente de recursos humanos generar estadísticas de empleados por departamento. El reporte muestra para cada departamento: la lista de departamentos asociados, el total de empleados por departamento, y el departamento más activo de cada categoría. El sistema debe calcular automáticamente estos datos y mostrarlos organizados por popularidad.
